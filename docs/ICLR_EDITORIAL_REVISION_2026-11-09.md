# ICLR 稿件：主线与英文精修

本轮按“先完成 ICLR 稿件，后续期刊版再拓展研究”的方向，编辑正文、附录和图注。
没有增加实验，也没有根据已有测试结果更换配方、种子或筛选标准。

## 新版标题与核心论点

**Silent Scale Shift: When Shared Updates Break Existing Readouts**

全文围绕一个问题展开：新的特征仍能完成任务，为什么旧读出会失效？
尺度修复与成对对齐提供诊断证据；有符号更新分析解释监测盲点；兼容性控制
检验保住旧接口的收益与成本。这样，读者先看到现象，再理解机制和适用条件。

## 主要编辑

- 重写摘要和引言，集中呈现匹配续训、真实重建与兼容性确认的证据。
- 将尺度失效机制放在梯度诊断之前，先解释读出的问题，再引入分析工具。
- 将 CNN、头部状态及协议差异放在跨任务证据中，减少正文来回切换。
- 区分输入修复、兼容性保护和选择性过滤各自回答的问题。
- 精修附录的诊断、尺度分析、读出迁移和兼容性实验解释，删去重复的否定式辩护。
- 统一美式拼写；补全 NLL、ECE、STF 的首次定义。
- 编辑全部 17 张图的说明文字，并修订相关表注。保留图中种子、误差和原始数值。
- 同步 README、引用元数据与一处生成表注的引号错误。

例如，旧版用“the frozen readout is not a straw man”回应潜在质疑；新版直接说明
“The unchanged readout models a fixed deployment interface behind a changing encoder”。
类似地，修复段落直接解释输入映射改变了什么、保留了什么，把必要的收益范围
放到对应实验中说明，不在每次陈述结果后重复辩护。

## 保留的科学边界

参考编码器的 2.37 倍 CPU 推理成本仍在摘要、引言和结果中；单编码器与非线性
侧路未达到完整收益目标，CNN 的近阴性结果、固定划分与种子区间的含义、离线
诊断与实际 Adam 更新的区别、监测集与确认实验的范围也均保留。既有投影、
对齐和侧路方法的文献归属没有改变。

## 写法参考

阅读了 [Vision Transformers Need Registers](https://arxiv.org/html/2309.16588v2)
和 [Are Emergent Abilities of Large Language Models a Mirage?](https://arxiv.org/html/2304.15004v2)
的原文。借鉴的是具体问题先行、用互补实验逐步解释现象、标题承载论证的结构。
前者的奖项由 [ICLR 官方公告](https://blog.iclr.cc/2024/05/06/iclr-2024-outstanding-paper-awards/)
核实。没有复制其措辞，也没有把它们作为本研究的新增实验证据。
