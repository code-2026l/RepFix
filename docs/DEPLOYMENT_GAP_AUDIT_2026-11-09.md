# 科学缺口审查与本轮判据

审查对象是本地 `paper/RepFix_ICLR2027.tex`、对应实验驱动及原始逐种子记录。
下列行号指本轮修改前的 `db12e0b` 版本，方便回溯；后续新增内容会改变行号。
本报告中的判断不等同于录用预测。

## 对外部方案的判断

方向有价值，但不能照着那段建议改摘要。最有价值的部分是要求证明：
真实辅助学习有收益、既有消费者可继续使用、修复的访问条件与成本可接受。
这比继续增加人工收缩剂量更能回答效用问题。视觉骨干复现也值得做。

四处关键论断需要纠正：

1. **没有新标签，不等于没有可复用的旧训练标签。** 原稿的 refit 在旧 fitting
   集上训练新线性头，未收集新标签。它是合理的监督访问对照，不能称为作弊。
   真正需要分开的是：只有旧统计量、能保存配对旧特征、仍有拟合标签三种权限。
2. **0.453→0.938 与 0.826→0.947 是不同实验。** 前者主要是尺度修复，后者是
   真实重建任务上的配对线性对齐。不能拼成一次“无标签统计重校准救回0.947”。
   历史表的0.241→0.952又属于分别训练的编码器，不能替代匹配 continuation。
3. **CIFAR 的大跌和近乎完整恢复都是待检验假设。** 不能预写75→20→74，
   更不能由一个种子推导普遍规律。使用测试图像拟合统计量属于另一种评估协议，
   本轮使用预先隔离的训练锚点，开发阶段不打开官方测试集。
4. **尺度边界、零空间控制和坐标修复回答不同问题。** 仿射边界是给定尺度模型
   的精确结果；零空间保证输出约束可实现；成功修复是某个变换族的经验解释。
   三者都不能证明所有漂移只有尺度成因。2.37倍参考编码器成本也必须可见。

“部署与持续学习”不是尚未有人研究的空白。BCT 已研究版本兼容；LDC 已把旧
原型失效与仍保留判别信息联系起来，并通过无类别标签的旧/新特征映射补偿漂移。
LDC 还包含 ResNet-18/CIFAR-100 等实验。因此，仅换叙事和补这个数据集不构成
决定性新颖性。AdaBN、Tent 又已经建立无标签归一化适应的先例。

直接核对的原始文献：

- [BCT, CVPR 2020](https://arxiv.org/abs/2003.11942)
- [LDC, ECCV 2024，正文3.2–3.3](https://arxiv.org/html/2407.08536v1)
- [AdaBN](https://arxiv.org/abs/1603.04779)
- [Tent, ICLR 2021](https://arxiv.org/html/2006.10726v3)
- [On Pitfalls of Test-Time Adaptation, ICML 2023](https://proceedings.mlr.press/v202/zhao23d.html)

本稿可以争取的区分点是：在辅助更新中分离尺度、信息和接口失效；把精确局部
机制、匹配更新、固定修复族及带弃权的消费者检查连起来。要把它升级成广泛有效
的新方法，仍需独立的收益—兼容性—成本证据，以及与更近邻方法的直接比较。

## 已固定的突破尝试

完整判据见 [计算前提交的方案](plans/2026-11-09-deployment-chart.md)。

第一条路线把配对坐标修复放在非线性学习之后。若最后一层是仿射层，
`h_emit=h_native M+b` 可折入编码器；可逆M还能把当前头反向重写，使当前logit
在实数算术中保持。它没有精确保住旧输出的保证，也不声称线性对齐或矩阵折叠
是新的算法家族。要检验的是它能否跨过此前的学习能力/部署成本瓶颈。

第二条路线是ImageNet预训练ResNet-18在CIFAR-100上的旋转辅助继续训练。
它使用64像素输入、冻结BN运行统计、完全可训练的网络权重、独立训练锚点与
验证集。所有三分支和四个锚点预算都保留。人为缩放和协方差保持的旋转是
机制对照，不能算作真实辅助更新的泛化结果。

这轮的成功标准不是“多跑出一张好看的图”，而是固定方案中所有指标同时过关。
阴性结果意味着需要保留缺口，不会通过更改门槛把它改成成功。
