# Cached-anchor risk controls

The mapping already accesses1024 paired healthy outputs. Check whether reusing
them removes the need for new monitor queries. This is a fixed retrospective
control on the twelve saved endpoints, not fresh independent confirmation.
Do not change the primary visual auxiliary study or call a standard ridge
leave-one-out identity a new statistical method.

Reconstruct the same ridge design on exactly those1024 fitting anchors. Keep
its full-design feature normalizer fixed and use the same n*lambda penalty,
lambda=.001, with an unpenalized intercept. Compute leverage h_i and exact
leave-one-row-out predictions y_i-(y_i-yhat_i)/(1-h_i). Export only these
numerical outputs and leverage, with all source/checkpoint hashes. Check the
full ridge fit against the prior exported cheap-anchor predictions.

Locally evaluate four zero-additional-query estimators: in-sample decision
counts, in-sample isotropic residual propagation, leave-one-out decision counts,
and leave-one-out isotropic residual propagation. Propagation uses the preceding
512 cheap-input subset and64 common Gaussian draws (seed6700), unchanged.
Compare with the frozen32/64-query estimators from the preceding study using
the same full-corpus maximum-of-three-consumer target and four-reference means.
Keep clean and fixed augmented outcomes, every endpoint and every estimator.
The initial1024 paired outputs remain an explicit cost. Neither reuse nor
leave-one-out supplies a finite-corpus or future-population certificate.

Run only CPU numerical reconstruction remotely; all code, analysis, plots and
writing stay local. Use opaque roots and the existing total concurrency rules.
